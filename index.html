SUPABASE CLOUD LIBRARY

⚙ จัดการเพลง (Admin)

บัญชี Admin ต้องสร้างใน Supabase Authentication และเพิ่มสิทธิ์ในตาราง admin_users ตาม README ก่อน

อัปโหลดไฟล์เพลงลง Storage และบันทึกรายการเพลงใน Supabase ทุกเครื่องจะเห็นรายการเดียวกัน

เพลงในระบบ

การเพิ่ม–ลบไฟล์ถูกตรวจสิทธิ์โดย Supabase RLS ไม่ใช่เพียงซ่อนปุ่มในหน้าเว็บ

วิธีใช้งานตู้เพลง

1. กดหมวดเพลงเพื่อดูรายการ หรือใช้ช่องค้นหา และกด ＋ เพื่อเพิ่มเพลงลงคิว

2. เลือกเพลงจากรายการแล้วกดเล่น/พัก คิวเพลงจะเล่นต่ออัตโนมัติ และสามารถเลื่อนคิวขึ้นลงได้

3. เชื่อมต่อ Supabase ให้โดยอัตโนมัติ เมื่อรัน SQL และตั้งค่า Admin เรียบร้อย สามารถล็อกอินเพื่อเพิ่ม แก้ไข หรือลบเพลง

4. เพลงบน Supabase แชร์รายการข้ามเครื่อง คิวเพลงเป็นคิวส่วนตัวเฉพาะแท็บนี้ และ Equalizer วิเคราะห์เสียงจริงจากไฟล์ที่อนุญาต CORS
