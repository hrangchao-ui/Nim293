เพลงมันวัยเก๋า — NEON 80s JUKEBOX (Mobile Edition)

คุณสมบัติ
- สีสันนีออนสดใส ออกแบบ Mobile First สำหรับหน้าจอมือถือแนวตั้ง
- รูปภาพหน้าปกเดิม, หมวดเพลง 4 หมวด, ค้นหาและเล่นเพลง
- คิวเพลง: กด ＋ ที่รายการเพลงเพื่อเพิ่มคิว, ปุ่ม ↑ ↓ เพื่อสลับลำดับ, ✕ เพื่อลบ, ปุ่มล้างคิว
- เมื่อเพลงจบ จะเล่นเพลงจากคิวก่อน แล้วจึงเล่นเพลงถัดไปจากรายการปัจจุบัน
- Equalizer ใช้ Web Audio API วิเคราะห์ความถี่ของไฟล์เพลงจริงเมื่อเบราว์เซอร์รองรับ
- หน้าต่าง Admin สำหรับเพิ่ม/ลบเพลง MP3/WAV/M4A หรือ URL ไฟล์เสียงโดยตรง

วิธีใช้
1. แตกไฟล์ ZIP โดยเก็บโฟลเดอร์ assets ไว้ด้วย
2. เปิด index.html ด้วย Chrome, Edge หรือ Safari; หากเบราว์เซอร์จำกัด file:// ให้เปิดผ่านเว็บเซิร์ฟเวอร์ (เช่น python -m http.server 8000)
3. กด “จัดการเพลง” เพื่อเพิ่มเพลงของคุณ
4. เลือกหมวดและชื่อเพลงเพื่อเล่น หรือกด ＋ ข้างชื่อเพลงเพื่อเพิ่มคิว
5. กด “เปิดคิวเพลง” เพื่อเลื่อนไปจัดคิวเพลงด้านล่าง

ข้อจำกัด
- เพลงและรายการที่เพิ่มถูกเก็บในเบราว์เซอร์เครื่องเดียว (IndexedDB + localStorage) ไม่ซิงก์ข้ามอุปกรณ์
- คิวเพลงเป็นคิวของเซสชันปัจจุบัน
- ระบบ Admin ยังไม่ใช่ระบบล็อกอินพร้อมฐานข้อมูลส่วนกลาง
- URL ไฟล์เสียงจากเซิร์ฟเวอร์อื่นต้องเข้าถึงได้และอาจต้องอนุญาต CORS สำหรับ Equalizer หากเว็บปลายทางจำกัดการเข้าถึงข้อมูลเสียง
- ลิงก์ YouTube ไม่ใช่ URL ไฟล์เสียงและใช้กับเครื่องเล่นนี้ไม่ได้
- ใช้เฉพาะเพลงที่มีสิทธิ์ใช้งาน
